## [1.0.0] - 2025-11-30

### Added
- Shared fog of war exploration between all players
- Shared map pins visible to everyone
- Server-enforced configuration via JSON
- Client-side BepInEx configuration
- Chunked data with compression for network efficiency
- Persistent storage across server restarts
- Force public position option
